# PIT Navigator knowledge base

Ovaj folder sadrži v1.0 knowledge base za početno RAG testiranje PIT Navigatora.

## Kako koristiti bazu

- `00_overview/` je početna mapa: pregled programa, poređenje PIN 2020 i PIT 2027, indeks i changelog.
- `01_courses/2027/` sadrži course dokumente za glavne predmete u PIT 2027.
- `03_course_plans/2025_2026/` sadrži aktuelne planove rada za obrađene predmete.
- `04_baskets/2027/` sadrži tematske korpe, preporuke i kratke reference za izborne predmete bez posebnog course dokumenta.
- `05_retrieval_guides/` sadrži retrieval mapu, intent primere i test pitanja.
- `06_policy/` sadrži answering policy i QA checklist.

Za RAG testiranje prvo koristiti `00_overview/knowledge_base_index.md`, zatim `05_retrieval_guides/pit_navigator_retrieval_map.md` i `06_policy/pit_navigator_answering_policy.md`.

## Status

v1.0 je spremna za početno RAG testiranje.
